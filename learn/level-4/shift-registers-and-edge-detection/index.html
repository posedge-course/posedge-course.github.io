4.3 Shift registers and edge detection

Teaches Shift register (circuit), Edge detector (circuit). About 6 minutes.

Lesson 2.2 put two flip-flops in a row, the second taking the first. Make the row longer and you have a shift register: at every rising edge, each bit takes the value of the bit before it, and the first bit takes a new input.

Braces join

{q[2:0], d} is a concatenation: the braces join vectors and bits into one wider vector, the leftmost part at the top. Three bits and one make four, so at each edge q[3] takes q[2], q[2] takes q[1], q[1] takes q[0], and q[0] takes d. Every right-hand side is read before anything changes (lesson 2.2), so q[0] is d from one edge ago, and q[3] is d from four edges ago.

A shift register keeps things in step. If a result takes four cycles to work out, a flag that says "this input is valid" can go through four flip-flops and arrive with it.

Inside the FPGA

Some of the FPGA's LUTs can also work as a shift register, with no flip-flops, of up to 32 bits in one LUT. A LUT shift register of up to 16 bits is an SRL16E. Vivado builds delay16, a 16-bit version of Listing 1 whose only output is its last bit, from one SRL16E for the middle of the line and two flip-flops for its ends. An SRL16E cannot be reset, so delay16 with a reset takes 16 flip-flops instead.

Edge detection

A button, or a signal that says a job is done, is a level: it stays 1 for many cycles. To act once, you want a pulse: 1 for one cycle, when the level goes from 0 to 1. Listing 2 is an edge detector, a 2-bit shift register and one gate.

hist[0] holds level from the last edge, and hist[1] from the edge before. rise is 1 when the newer one is 1 and the older one is 0: in the cycle after level rose. Vivado builds it from two flip-flops and one LUT2.

Show answer and explanation

The bug is on line 14, assign rise = ~hist[0] & hist[1];. It should read assign rise = hist[0] & ~hist[1];.

hist[0] is the newer value and hist[1] the older one, because hist[0] takes level and hist[1] takes hist[0] (lesson 4.3), and the shift line does that correctly. The gate in this file is 1 when the newer value is 0 and the older one 1, so it pulses after level falls. Written hist[0] & ~hist[1], it is 1 after level rises.
