11.2 Four taps a cycle

Teaches Banked memory (circuit). About 6 minutes.

The decoder's second layer needs 9,801 products at each of its 81 positions, and the chip has 240 DSP blocks. So it reuses its multipliers over the kernel's taps, a few taps a cycle.

Layer one takes a whole kernel row, 11 taps, each cycle; layers two and three take 4. Each tap is a read. Layer one's input is small, 4 bits a position, so the decoder keeps 11 copies of it, one for each tap. The hidden maps hold 9 channels a position, 99 or 189 bits: four copies would take four times the memory.

Banks

So each hidden map is stored once, split over four banks: four memories side by side, each with its own read. Number a map's positions in raster order, along a row and then the next row down. Position i lives in bank i mod 4, at row i / 4, rounded down: a bank's row is an address in that bank, not a row of the map. Any four neighbouring positions then sit in four different banks: 6, 7, 8 and 9 are in banks 2, 3, 0 and 1, rows 1, 1, 2 and 2. Each bank gives one word a cycle, so all four come in one cycle.

To read four positions from a base a, write it as a = 4q + r: q is the base's row and r its bank. Bank b reads row q + 1 if b is less than r, and row q otherwise. The words come out in bank order, and lane j takes the word of bank (r + j) mod 4, which puts them back in order (Figure 1).

This works only for neighbours in raster order. A kernel row's taps are neighbours; the kernel's next row starts a whole map row further on. So the decoder keeps each group of four taps inside one kernel row: 11 taps make groups of 4, 4 and 3, and a kernel takes 33 cycles where 31 would do. That 6.45% buys reads that never need one bank twice.

Two banks

bank2 (Listing 1) does the same with two banks: bank 0 holds the even positions, bank 1 the odd ones. Each bank is read at the rising edge, like the block RAM of lesson 6.3, so the words come a cycle after the base. r1, the bank of that base, decides which word goes to which lane.

Questions

Question 1 of 3. Predict word0

Lesson 11.2's bank2 holds a map of single bits: positions 3, 4, 8, 9, 12, 17, 20 and 27 hold 1, the rest 0. base steps from 2 to 9, one a cycle. At each rising edge bank 0 reads its row for the base on the line, and its word is on word0 until the next edge. Cycles 0 and 1 are drawn for you. Set word0 for the rest.

Question 3 of 3. Find the bug

The bug is on line 29, assign row0 = q;. It should read assign row0 = r ? q + 4'd1 : q;.

For an odd base, base + 1 is even, so it is in bank 0, one row further down: 3 is in row 1 of bank 1, and 4 in row 2 of bank 0. Bank 0 must read row q + 1 when r is 1. Reading row q always, it returns base − 1.
