1.2 Operators become look-up tables

Teaches Logic operators (primitive). About 5 minutes.

Lesson 0.2's alarm used two operators, & (and) and | (or). A third is ~ (not), which turns 0 into 1 and 1 into 0. These are bitwise operators: on a vector they work on each bit separately, so ~ turns 0110 into 1001.

Listing 1 is that alarm with one more input. While someone tests the alarm, test is 1 and the siren stays quiet.

Not one gate per operator

In lesson 0.2, Vivado built the alarm as one LUT3, not as an OR and an AND. Here is why. For each output, synthesis finds the inputs that output depends on and works out the output for every combination of them. That is a truth table, and a truth table is what a LUT holds (lesson 0.1).

siren depends on four inputs, so its truth table has 16 rows. A LUT that uses four of its inputs, a LUT4, holds all 16, so the whole alarm becomes one LUT4 (Figure 1). The signal opening disappears into the table, as it did in lesson 0.2.

What logic costs

So logic costs inputs, not operators. An output that depends on up to six inputs fits in one LUT, however many operators its expression uses. An output that depends on more than six needs more than one LUT, joined together.

Question 2 of 4. Fill the blank

The siren must stay quiet while test is 1. Type the operator that goes in front of test.

hdl/level-01/quiet_alarm/quiet_alarm.sv

1// Lesson 0.2's burglar alarm with one more input: while someone is testing
2// the alarm, the siren stays quiet.
3module quiet_alarm (
4 input logic armed, // 1 when the alarm is switched on
5 input logic door_open, // 1 while the door is open
6 input logic window_open, // 1 while the window is open
7 input logic test, // 1 while someone is testing the alarm
8 output logic siren // 1 to sound the siren
9);
10 logic opening; // 1 when the door or the window is open
11
12 assign opening = door_open | window_open;
13 assign siren = armed & opening & (blank)test;
14endmodule
Show answer and explanation

The blank is ~. Also accepted: !.

~test is 1 while test is 0, and 0 while test is 1. ANDed with the rest, it lets the siren sound only when no test is running. (! gives the same result on a single bit, but this course uses ~, which also works on every bit of a vector.)

Question 3 of 4. Read the report

Vivado built quiet_alarm.sv, four operators on four inputs, for the Arty A7-100T. Below is the Primitives table of its Utilization report: one row for each kind of cell, with how many the design uses. A LUT4 is a LUT that uses four of its inputs.

vivado/reports/quiet_alarm/arty-a7-100t/utilization.rpt, lines 180 to 186. Written by Vivado.

How many LUT4 cells did Vivado use for the whole alarm?

Show answer and explanation

The report says 1.

Read the LUT4 row. siren depends on four inputs, so its truth table has 16 rows, and one LUT4 holds them all: the OR, the NOT and both ANDs are inside it, and so is opening. The IBUF and OBUF rows are the pin buffers of lesson 0.3, one for each input and one for the output.
