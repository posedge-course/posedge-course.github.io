1.1 Signals, vectors and assign

Teaches Vector (primitive). About 6 minutes.

A logic signal is one bit: 0 or 1. To hold a number, you group bits under one name into a vector. logic [3:0] a is a vector of four bits, numbered 3 down to 0; [3:0] is its range. Bit 3 is worth 8, bit 2 is worth 4, bit 1 is worth 2 and bit 0 is worth 1, the least, so a holds any number from 0 to 15.

Width

The number of bits is the vector's width, and it sets the largest number the vector can hold. Each extra bit doubles how many values it holds: four bits hold 0 to 15, and five bits hold 0 to 31.

Listing 1 adds two 4-bit numbers. Their sum can reach 15 + 15 = 30, which does not fit in four bits, so sum is declared with five. In general, the sum of two N-bit numbers needs N + 1 bits.

The first assign adds. sum[3:0] takes bits 3 to 0, which is called a part-select, and sum[4] takes one bit, a bit-select. Bit 4 is worth 16: it is the carry, the 1 that the top column passes on, as in adding on paper. So carry is 1 exactly when the sum is 16 or more. Figure 1 shows 9 + 8 = 17: low is 0001 and carry is 1.

If sum had only four bits, a + b would lose its top bit, and no tool would complain about the addition itself, because both numbers are four bits wide. So you work out each width yourself, from the largest value the signal must hold.

Vectors on a waveform

A waveform draws a vector as one lane, with its value written in hexadecimal: the digits 0 to 9, then A to F for 10 to 15. One hex digit is exactly four bits. To turn it into bits, write it as a sum of 8, 4, 2 and 1: C is 12, which is 8 + 4, so C is 1100. On a waveform, low shows 1 for a sum of 1 and also for a sum of 17; only carry tells them apart.

Question 2 of 4. Fill the blank

adder8 adds two 8-bit numbers, each from 0 to 255. Type the range sum needs so that no total ever loses a bit.

hdl/level-01/adder8/adder8.sv, lines 1 to 11

1// Adds two 8-bit numbers a and b, each 0 to 255. low is the sum's eight
2// low bits, and carry is 1 when the sum is more than 255.
3module adder8 (
4 input logic [7:0] a,
5 input logic [7:0] b,
6 output logic [7:0] low,
7 output logic carry
8);
9 logic (blank) sum; // the sum of a and b
10
11 assign sum = a + b;
Show answer and explanation

The blank is [8:0].

The largest total is 255 + 255 = 510. Eight bits hold 0 to 255 and nine hold 0 to 511, so sum needs nine bits, as lesson 1.1's rule says: two 8-bit numbers need 8 + 1. A range counts down to bit 0, so nine bits are [8:0]. With [7:0], every total above 255 would lose its top bit. No tool complains about the addition itself; only a line that reads bit 8, such as the one that gives carry, would get a warning.

Question 3 of 4. Fill the blank

adder8's carry must be 1 exactly when the total is more than 255. Type the bit-select of sum that gives it.

hdl/level-01/adder8/adder8.sv, lines 12 to 13

12 assign low = sum[7:0];
13 assign carry = (blank);
Show answer and explanation

The blank is sum[8]. Also accepted: sum[8:8].

Bit 8 of the nine-bit sum is worth 256: each bit is worth twice the one below it. Every total from 256 to 510 has it set, and every total from 0 to 255 has it clear, so sum[8] is the carry. The eight bits below it, sum[7:0], are low.
