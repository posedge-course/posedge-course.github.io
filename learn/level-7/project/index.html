Level 7

Level 7 project Hello from the board

Write hello in my_hello.sv until hello_tb.sv prints TEST PASSED, and write my_hello.xdc from Digilent's master XDC; on the board, each press of BTN0 prints hello in a serial terminal. About 60 minutes in simulation.

Level 5's transmitter sends one byte when it is told to. This project gives it something to say: a sender that hands it the characters of "hello", one at a time, each time you press a button, and a constraints file that puts the whole design on the board's pins. It uses level 4's press for the button, level 5's uart_tx and two-block controller, and every lesson of this level. The simulation path needs only Icarus Verilog and the waveform viewer; the board path ends with "hello" on your PC.

The design

The ports of hello

The parameters of hello
ParameterDefaultWhat it sets
TBITS10uart_tx's timer width
LAST867uart_tx's last timer value: 868 cycles a bit, 115,200 baud at 100 MHz
PBITS20press's counter width
HOLD999_999how long press waits for the button to settle: about 10 ms

The message is seven characters: h, e, l, l, o, then a carriage return, 0D, which takes the terminal back to the start of the line, and a line feed, 0A, which moves it down. A press while the message is going out must change nothing.

The files you write are my_hello.sv and my_hello.xdc; the module inside is hello, the name the testbench uses. hello_tb sets every parameter small, so that a bit lasts 5 cycles and a press settles in a few.

What you see when it works

  • The run prints TEST PASSED: the receiver model read hello and its new line twice, once for each press that came while the sender was idle.
  • In the waveform, the first character's data bits read 0, 0, 0, 1, 0, 1, 1, 0 from bit 0: 0110_1000 from bit 7, 68 in hexadecimal, h.
  • With the board: each press of BTN0 prints hello on a new line. Pressing BTN0 again while a message is going out changes nothing, and BTN1 stops a message part-way (the character on its way may arrive garbled).

If it fails

  • syntax error, followed by Invalid module instantiation: the command lacks -g2012. Add it.
  • Unknown module type: hello: the module in my_hello.sv has another name. It must be called hello.
  • press.sv:15: error: Unknown module type: debounce: a file is missing from the command. All six files of the run step must be named.
  • TEST FAILED: tx=x before any press at 70 ns: nothing drives tx. Connect uart_tx's tx to it.
  • TEST FAILED: received 48, expected 68 at 630 ns: a character's code is wrong: 48 is a capital H. Check the codes against the list in the steps.
  • TEST FAILED: received 68, expected 65 at 1830 ns, then 2 characters after one message: the sender moves on without waiting for busy to fall, and uart_tx ignores a send while it is busy. Leave WAIT only when busy is 0.
  • TEST FAILED: received 65, expected 6c at 2190 ns: a press while the message goes out starts it again. Only IDLE may take a press.
  • TEST FAILED: received 0a, expected 68 at 6130 ns: the second message starts where the first ended. Set index to 0 when IDLE takes a press.

These messages are from Icarus Verilog 12.

On the board (optional)

You need an Arty A7 and Vivado for this part. Everything above works without them.

The board steps use Vivado's project mode, as in the earlier projects. Listing 1 is the line of the course's timing summary that says every constraint is met; look for the same line in yours.

If the terminal shows nothing, check that it is open on the board's serial port, and that tx is on the line to the PC (lesson 7.1). If it shows the wrong characters, check its baud rate and your LAST (lesson 7.3). If DONE does not light, programming did not finish: program the board again.

Files for this project

The same files the course checks: save them into one folder on your computer.

Your checklist

Simulation path

  1. Make a new folder and save the five files listed above into it. hello_tb.sv is the specification: a receiver model inside it reads every character from tx. You may use your own my_uart_tx.sv from level 5 in place of uart_tx.sv.
  2. Make a file my_hello.sv with a module named hello, the parameters in the second table with their defaults, and the four ports in the first.
  3. Inside, place a press (level 4's project) on btn, with BITS set to PBITS and HOLD to HOLD, and a uart_tx (level 5's) with BITS set to TBITS and LAST to LAST, its tx on your tx.
  4. Add a 3-bit index and an always_comb block with a case that gives the character to send for each value: 68, 65, 6C, 6C, 6F, 0D, 0A in hexadecimal. Write each as 8'h68: 'h gives the digits in hexadecimal, as 'b gives them in binary (lesson 1.3). Wire it to uart_tx's data.
  5. Add the sender in the two-block form (lesson 5.2), with the states IDLE, SEND and WAIT: a press takes IDLE to SEND; SEND lasts one cycle, with uart_tx's send at 1, and goes to WAIT; once busy is 0, WAIT goes back to SEND, or to IDLE after the seventh character. Set index to 0 when IDLE takes a press, and add 1 to it when WAIT finds busy at 0.
  6. Run iverilog -g2012 -o hello_sim hello_tb.sv my_hello.sv uart_tx.sv press.sv debounce.sv edge_detect.sv, then vvp hello_sim, until it prints TEST PASSED.
  7. Open hello_tb.vcd and add from dut your press pulse, index, and the signals on uart_tx's send and busy; then add tx. Find the first press and read the first character's eight data bits, bit 0 first.
  8. Make my_hello.xdc from Digilent's master XDC for the Arty A7 (lesson 7.1): clk on the 100 MHz clock with a create_clock of 10 ns (lesson 7.2), btn on BTN0, rst on BTN1, tx on the USB-UART line to the PC, and LVCMOS33 for all four. Then compare it with the course's file after the checklist.

On the board (optional)

  1. In Vivado, create an RTL project for xc7a100tcsg324-1 with your five design files (my_hello.sv, uart_tx.sv, press.sv, debounce.sv and edge_detect.sv) and my_hello.xdc, and run Generate Bitstream. hello_tb.sv stays out: a testbench is never built.
  2. Open the timing summary and check that every constraint is met, as Listing 1 above says for the course's build.
  3. Program the board (lesson 7.3), then open a serial terminal on the board's serial port at 115,200 baud, 8 data bits, no parity and 1 stop bit.
  4. Press BTN0: hello appears in the terminal, on a line of its own, once for each press.
