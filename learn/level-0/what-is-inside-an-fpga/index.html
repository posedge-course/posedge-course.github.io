0.1 What is inside an FPGA

Teaches Look-up table (LUT) (primitive). About 5 minutes.

An FPGA (field-programmable gate array) is a chip whose circuit you choose after it is made. Load a different design into it and it becomes a different circuit.

Look-up tables

Its logic is mostly look-up tables, or LUTs. A LUT is a tiny memory that holds a truth table: every combination of its inputs, with the output for each. The inputs form an address that picks one row, and the bit stored in that row is the output.

Each LUT on the FPGA this course uses, on Digilent's Arty A7 board, has six inputs, so its table has 64 rows. Any function of up to six inputs can be written as such a table, so one LUT computes any of them. The bits are stored when the design is loaded into the chip. After that, a new value on an input only picks a different row. Around the LUTs are flip-flops, which remember bits (level 2), wiring that can join any of them to any other, and pins that reach the board's switches and LEDs.

Your first design

Listing 1 says that y is 1 when at least two of a, b and c are 1. & means "and" and | means "or", so its assign line reads: y is 1 when a and b, or a and c, or b and c, are both 1.

Vivado, the program that builds designs for this FPGA (lesson 0.3), builds the vote from the FPGA's cells, its building blocks, such as a LUT. Figure 1 shows the result: one LUT that uses three of its six inputs, which Vivado calls a LUT3. Its other three inputs are not used, so only a, b and c pick a row: in effect it holds eight rows. The table under it shows them, taken from a simulation of the code. This FPGA has tens of thousands of LUTs; this design uses one.

Reading a waveform

The questions draw signals as waveforms. Time runs from left to right in steps of 10 ns, and each column is one step. A line drawn high is 1, and a line drawn low is 0. You set the output for each step, then check it against a simulation of the real code.

Questions

Question 1 of 3. Predict y

Each column is one step. This LUT3 holds vote's truth table: y is 1 when at least two of a, b and c are 1. Steps 0 and 1 are drawn for you. Set y for the rest.

Question 2 of 3. Put the steps in order

Put these in the order they happen in vote's LUT.

  • Together they pick one of the eight rows.
  • The LUT reads the bit stored in that row.
  • That bit appears on y.
  • The design is loaded into the chip, and the LUT's eight bits are stored in it.
  • a, b and c take new values.
Show answer and explanation

In order:

  1. The design is loaded into the chip, and the LUT's eight bits are stored in it.
  2. a, b and c take new values.
  3. Together they pick one of the eight rows.
  4. The LUT reads the bit stored in that row.
  5. That bit appears on y.

A LUT does not work anything out when its inputs change. Its eight bits, one for each row of vote's truth table, were stored when the design was loaded. After that, each new set of inputs only picks a row, and the bit already stored there becomes the output. That is why one LUT can hold any function of its inputs: a different design only stores different bits.

Question 3 of 3. Predict y

This LUT3 holds the truth table of an odd count: y is 1 when an odd number of a, b and c are 1, that is one of them or all three. Set y for every step.
