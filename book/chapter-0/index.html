Chapter 0 What an FPGA is

This chapter is being written. Below is its outline: a heading for each section, with what it will cover. Until it is written, level 0's lessons teach the same.

Outline

  1. What is inside an FPGA

    An FPGA's logic is mostly look-up tables, tiny memories that hold truth tables, which loading a design fills in.

  2. HDL describes hardware

    Each assign line describes a piece of a circuit that exists and works all the time, so the order of those lines does not matter.

  3. The build flow

    Vivado turns code into a configured chip in fixed steps: synthesis, constraints that pick the pins, place and route, and the bitstream.

  4. The tools and what each does

    A simulator runs a design in seconds with every signal visible, so designs are simulated before they are built.

  5. A first simulation

    Install a simulator and a waveform viewer, run a testbench, and check its waveform against a truth table.
